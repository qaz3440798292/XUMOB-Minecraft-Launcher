# XUMOB Minecraft Launcher v0.5.0 · Modrinth 下载

## 使用

1. 关闭旧版，解压新版并运行 `XUMOB Minecraft Launcher.exe`。
2. 在游戏库选择要安装内容的目录和版本。旧版设置可在关闭软件后迁移程序旁的 `data` 文件夹。
3. 打开左侧“下载中心”，选择“模组 / 资源包 / 光影”，输入关键词搜索。
4. 选择项目和兼容版本，点击“查看安装清单”，核对目标实例及必要前置。
5. 点击“确认下载并安装”。下载进度会显示在右侧；结束后可到模组列表查看新增 JAR。

模组按当前 Minecraft 版本与 Fabric、Forge、NeoForge 或 Quilt 加载器匹配。原版实例可下载资源包与光影，安装模组需要先选择已有模组加载器的实例。下载资源包和光影后，在游戏内选择启用；光影需要 Iris 或 OptiFine。

不需要登录 Modrinth，也不需要 API Key。正版登录的应用许可与 Modrinth 下载是两套独立服务，Minecraft 登录失败不会阻止下载中心的公开内容查询。

## 安装行为

- 写入所选实例实际使用的游戏目录，自动沿用“版本独立 / 共享 / 自动识别”设置。
- 只下载所选版本的主要文件与平台声明的必要前置，忽略可选及内嵌依赖。
- 官方 Modrinth API 与 CDN，下载后验证 SHA-512 和文件大小，再提交完整文件。
- 已存在且一致的文件跳过；同名不同内容、项目旧版本或声明的不兼容内容会提示处理。
- 可以取消传输；失败或取消时清理临时下载，并撤回本次未完成的安装。全部提交成功后，文件成为正常安装内容。
- 游戏运行期间禁止安装；下载期间锁定实例和启动操作。关闭正在下载的启动器会先取消任务并等待清理。

前置判断依据平台元数据，不能替代项目作者对特殊配置、外部依赖和运行环境的说明。项目页入口位于右侧详情中。

已有项目识别使用 Modrinth 收录的文件哈希；修改过或平台未收录的模组可能无法自动识别为同一项目，安装前仍应核对整合包的额外兼容要求。

本版支持模组、资源包和光影。Minecraft 版本、加载器及 `.mrpack` 整合包的在线安装不包含在本次功能中。单文件上限 512 MB，单次安装上限 2 GB、64 个项目。
